## 一、结论（一句话）

以 Quiet 探针为基底：**暖象牙/暖炭双主题平涂、灰度做层级、朱砂唯一强调色、宋体只给文档标题、印章只做 logo、动效只留状态性**——「Claude 式的安静书桌」；结构采用 AI 桌面三栏（侧栏 / 文档主列 / 右栏 AI），学习主体是**文档**（讲义/笔记/自测），不是对话流。

## 二、决策历程（探针试错记录，全部存于 `docs/design-probes/`）

| 探针 | 方向 | 结果与教训 |
|------|------|-----------|

| `ariadne-lumen-probe.html`（v3 暗夜金线） | 推翻纸墨，以神话（线/迷宫/光）做暗色 AI 工作台 | **AI 桌面骨架做对了**；金线/晕环/扫光/星图等语言全部越权——「产品感」被「设计感」淹没 |
| `ariadne-quiet-probe.html`（v4 Quiet，**采纳**） | ChatGPT/Claude/Grok 公共标准：平涂、灰度层级、单一强调色、零装饰 | **Nur 拍板为备选基线**；明暗双主题均已截图存档 |

对标竞品：ChatGPT（纯灰阶、无气泡助手消息）/ Claude（暖象牙底 + 衬线标题 + 单一赤陶橙——与 Ariadne 血缘最近）/ Grok（近黑极简）；对标国产同类 **Mentrix 录路岛**（实机走查，见 §七）。

公共标准（v4 即按此执行）：层级靠灰度不靠颜色；表面平涂无材质；强调色 ≤1 个且面积 <5%；圆角 + 细边框；侧栏 + 中列（+ 可选右栏）；动效仅流式淡入/光标；装饰为零。

## 四、结构（Clew 学习页为准；token 全局生效）

**范围说明：v4 的 token 层是全局的**——双主题、朱砂唯一强调、圆角、正文规格、宋体收缩、印章 logo、动效白名单写进共享 token 后所有页面继承，不存在「Clew 新语言、其他面旧语言」的过渡态。**三栏结构只是 Clew 学习页的布局**；其余页面保持各自的信息结构（题库 = 列表 + 答题列，计费 = 三列档位卡，官方课工作区语义不变——证据分级标签原样保留，v4 只动皮肤），用同一套语言重涂。营销首页 `/` 的概念（「从证据开始辨证」）保留，视觉语言归一到 v4。

- **左栏（264px）**：品牌 + 主导航（学习主环/Clew/官方课程/题库/会员）+ 本章知识点列表（纯文本行 + 药丸选中态）+ 底部配额小字。
- **中央文档主列（max-width ~700px 居中）**：面包屑 → 文档标题（宋体 30px）→ 元信息行 → 安静进度（2px 细线 + 一行小字）→ 视图 tabs（初学/复习/备考，下划线态）→ 讲义纯文本正文（无卡片包裹）→ 自测题与标记 chips。**（P0-1 已裁决，2026-10-04：安静进度线只替代八步教材管线 step-guide，保留线尾轻量「下一步」链接——它是八步推进的唯一导航；竖向环节脊柱与 LoopProfileBadge 保留，功能不动、视觉降噪到 v4 语言；文案措辞用「教材路径 6/8」，与 Loop Profile 环节数（3–6）明确区分为两套模型。）**
- **右栏（320px，常驻）**：问 Clew（头部状态点 + 当前知识点 chip + 消息区 + composer）。≤1200px 右栏下置（沿用 M3 断点行为），390px 单列。
- 工作台壳的「单任务/工作台」开关**保留（P0-4 已裁决，2026-10-04：Nur 选 B，双模式并行）**：workspace 模式 = v4 三栏呈现；focus 模式（追问下置）保留并重涂为 v4 语言；**默认模式改为工作台（v4 三栏）**，已保存 focus 偏好（`nur-learn:clew-study-mode=focus`）的用户尊重其选择，键沿用不删；**两种模式都过 v4 全套验收矩阵（1440/1200/980/390 × 明暗双主题）**。

## 五、唯一借鉴项（自 Mentrix 实机走查；Nur 裁决仅保留此件）

**Composer 显式控制**（交互层，无新视觉语言）：

1. composer 上方 chip 排：讲解风格（现位于讲义生成行动区 `<select>`，非 composer；v4 将其与「依据范围」一起做成 composer 上方 chip 排，语义裁决见 §十一 P0-3）+ 新增「依据范围」——仅依据讲义 / 讲义 + 教材原文 / 允许结合背景拓展（服务端 `chat-prompt.ts` 组装逻辑相应分支；属 Clew 服务区向后兼容新增，边界见 §九与 §十一 P0-2）；
2. AI 回答下方小图标行：复制 / 重新生成（**P2 语义已定**：「重新生成」= 对同一条提问重新请求一次，计入一次 ClewChats 配额，结果追加为新回答，不静默覆盖历史；「复制」= 纯前端复制该回答 markdown）；
3. 流式光标、消息形态不变。

## 六、差异化主张（写进官网与 onboarding 文案）

- 对话中心（Mentrix：好答案沉在聊天流）vs **文档中心（Ariadne：讲义生来可自测、可划重点、可派生三视图）**；
- 页级溯源内联（对齐 Mentrix 的行级引用呈现，保住「对照教材原文核对」的承诺）；
- 学习科学层纵深：自测 → 还需看 → FSRS → 三视图，竞品公开面上没有。
