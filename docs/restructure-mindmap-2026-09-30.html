分支 ①
学习闭环 · 整体架构
Learning Loop Architecture
  • 三层架构
    • 内容供给层
      官方课程（证据分级）· Hi doc（个人教材 AI 萃取）· 题库（15 套 / 9000+ 题）
    • 学习引擎层
      学 → 练 → 评 → 诊 → 复 → 迁移，六环节对所有供给线通用
    • 新建统一状态层
      LearningEvent 总线 · FSRS 调度 · 错题中心 · 弱 KP · 周计划 —— 三条线写入同一个学习者模型
  • 六环节闭环
    • 学
      lesson 讲义 / Hi doc 讲义 —— 理解
    • 练
      刷题 · 主观写作 · 病例四阶段 —— 应用
    • 评
      自核清单 · NUR 评分 · 模考 100 分 —— 反馈
    • 诊
      错题归因 · 弱知识点识别 —— 诊断
    • 复
      FSRS 间隔重复 · 即将遗忘提醒 —— 巩固
    • 迁移
      病例推理 · 跨场景应用 —— 会用
  • 执行路径（学生视角）
    • 日常
      /learn 今日任务（FSRS 到期 + 错题 + 周计划）→ 学练 → 确认尝试 → 状态更新
    • 每周
      周计划抽屉 → 弱 KP 定向训练
    • 考前
      模考 → 错题归因 → 回补知识点
分支 ②
Hi doc · 功能与路径
Personal Textbook Engine
  • 八步主路径（M0–M7 已建成）
    • 上传
      名额校验 · PDF 文字层 / DOCX · 扫描件明确拒绝
    • 目录识别
      启发式 + 模型，SSE 流式
    • 章节修正
      人工确认章节边界
    • 知识点萃取
      按章 SSE · 页码溯源
    • 讲义 + 追问
      每 KP 一份讲义 · Agent 对话
    • 划重点 / 批注
      选中即划 · 多色 · 备注
    • 学霸笔记
      讲义+追问+划重点 → 汇总导出
    • 课题工作坊
      ≤100 页短材料 · 检索答疑
  • 三个缺口（重构补齐）
    • 缺口学完即断
      讲义之后没有练 / 评环节，知识不固化
    • 缺口不进 FSRS
      萃取的 KP 无复习调度，学过就忘
    • 缺口孤岛
      与官方课、题库、错题中心零关联
  • 名额机制（已定案）
    • 当月有效
      basic 1 本 / pro 3 本 / max 10 本
    • 跨月冻结
      继续学需重占名额或升级档位；删除释放名额
分支 ③
官方闭环 × Hi doc · 连接
The Connective Tissue
  • 状态层贯通（核心）
    • 新建Hi doc 确认尝试 → LearningEvent
      与官方课同一事件模型
    • 新建统一 FSRS / 错题 / 弱点
      Hi doc KP 到期也出现在今日任务
    • 新建Agent 全局上下文
      知道你在三条线分别学了什么、错了什么
  • 能力复用
    • 新建Hi doc KP → 写作室
      一键进主观写作训练（复用现有房间）
    • 新建工作坊材料 → 病例室
      课题材料生成病例题，进四阶段推理
  • 内容升级通道
    • 新建优质生成物 → 提交审核
      学生的 Hi doc 笔记 / 讲义可申请进入官方课
    • 新建审核通过 → editorial 来源
      降低官方课 authoring 成本
    • 铁律不变
      证据分级（可关联/不可直接等同）只属于官方闭环；Hi doc 生成物永不自动进注册表
  • 导航贯通
    • 首页三入口
      官方课程 / Hi doc / 题库（已建成）
    • ⌘K + 左栏
      全局可检索、可跳转
