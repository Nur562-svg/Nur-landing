## 盘点边界与方法

- 原件保留原路径、原文件名、PDF 页码、PPT 幻灯片号和图片尺寸；未复制原文到浏览器静态资源。
- 排除了 `.DS_Store`、Word 锁文件、隐藏边车和已有 `tmp/` 目录中的 OCR、渲染页、脚本及其他派生物。
- 对每个候选文件计算 SHA-256；对 PDF 记录页数与文本层，对 PPTX 记录幻灯片数，对图片记录尺寸，对 ZIP 记录成员数。
- 对可读 Word/PPT/PDF 提取结构和文本；对扫描件和图片用本机 Vision OCR 做只读转录。OCR 只是检索辅助，不视为 `verified truth`。
- 对两本教材、历史试卷、疑似误标试卷、扫描题库、关键 Word 文档和三份 PPT 做了代表性视觉核验。
- 临时核验产物位于 `/tmp/nur-material-intake-20260718.vz8LqW/`，不属于产品数据，也不应被提交或部署。

## 状态语义

| 状态 | 本报告中的含义 |
|---|---|
| `pending` | 文件名、内容、来源、教师、offering 或完整性存在待确认问题，不能进入内容真相 |
| `available` | 文件存在、可读且有定位，但来源或答案尚未完全核验 |
| `verified` | 文件身份、版本和定位已核实；不自动证明文件内每个答案正确 |

本轮只有《生理学》第4版和《生物化学》第4版的出版社教材身份被核实为 `verified`。校级历史试卷暂为 `available`，因为页首学校/课程信息可见，但尚未获得学校原始发布链或教师确认。

## 可追踪冲突、重复与完整性问题

1. **字节级重复且错放**：MAT-020 与 MAT-080 的 SHA-256 完全相同，都是南京中医药大学《诊断学》2022–2023 试卷。内容属于西医诊断学，不属于中医诊断学或组织胚胎学。应保存为一个材料资产、两个原路径别名，不能重复入库。
2. **同课程第二份错放**：MAT-021 也是西医《诊断学》试卷，不能映射到《中医诊断学》。
3. **医古文疑似误标**：MAT-030 页首虽写《医古文》，题目却集中于《黄帝内经》地位、阴阳五行、四诊等中医基础理论；与 MAT-029 的训诂/词义题型明显不一致。暂列 `pending`。
4. **组织胚胎学答案冲突一**：“主要参与细胞内过氧化物分解的细胞器是”在 MAT-111 标为 B（线粒体），在 MAT-113 标为 D（微体/过氧化物酶体）；选项顺序一致，属于直接答案冲突。
5. **组织胚胎学答案冲突二**：“在中枢神经系统内参与髓鞘形成的细胞是”在 MAT-111 标为 B（少突胶质细胞），在 MAT-113 标为 C（小胶质细胞）；选项顺序一致，属于直接答案冲突。
6. **逻辑同源、非字节重复**：MAT-057《生理白皮.pdf》和 MAT-058《生理白皮（题库）.docx》正文高度同源，但格式、页数和修订状态不同。应建一个 source family，下挂两个 artifact version，不能仅靠哈希判断为两个独立来源。
7. **修订痕迹**：MAT-058 与 MAT-040 含 tracked changes。导入前必须决定使用“接受修订后”“拒绝修订后”还是保留双版本；当前不能静默选择。
8. **派生稿不能自证**：两门课程 `output/pdf/` 下的十二份背诵稿 PDF 元数据显示为 Codex 生成；它们是派生学习产物，不是独立教师或教材来源。
9. **题型笔记不等于 offering 真相**：MAT-118 记录了生理、生化、组胚、中诊题型结构，但没有正式发布链。只能作为 `user-provided` 候选，不能覆盖现有已锁定的中诊 offering 考试方案。
10. **OCR 与扫描件**：扫描 PDF/图片的 OCR 文本必须始终保留页码或图像 locator，并标记为转录；OCR 错字不能自动进入答案。

## 个人信息与版权边界

- OOXML/PDF 中存在作者、最后修改者、软件账户、旧模板和商业网址等元数据；这些信息不应进入前端或公开部署物。
- MAT-070《绪论学习任务.jpg》可见课堂人物头部，应视为可识别人物图像，不进入浏览器静态资源。
- 多份试卷含空白姓名/学号栏；虽未发现已填写的姓名或学号，仍应在导出缩略图时裁切或遮蔽表单区。
- 题库、教材和整页扫描件只保留本地原件与必要 locator；前端只存必要结构化学习内容，不能大段复制整本受版权保护材料。

## 映射到课程引擎的规则

| 材料层 | 推荐映射 | 处理规则 |
|---|---|---|
| 出版社教材 | `Source → Chapter → KnowledgePoint → Lesson/Evidence` | 教材正文与页码可支撑解释；不推断教师重点 |
| 教师课件候选 | `Source → KnowledgePoint → Lesson/Evidence` | 在教师、年份、offering 未确认前保持 `available`，不用 `verified` |
| 校级历史试卷 | `Source → Assessment.promptSource` | 保留原题措辞和页码；答案单独建权威，不从题干来源推导答案 |
| 校教研室题库 | `Source → Assessment.prompt/answer` | 题干与所附参考答案可分别引用同一 source family；仍不等于当前教师采分点 |
| 学生题库/背诵稿 | `Source → Assessment.answer` | 只能用 `student-compiled + unverified`；遇冲突同时保留变体，不自动选真 |
| NUR/Codex 派生稿 | `Source → NUR editorial explanation` | 必须记录 `derived-from`；不能提高原始来源权威 |
| 识图材料 | `Source → Assessment media` | 必须带文件、页/图号、染色、倍率、标签与答案来源；当前引擎尚不能完整表达 |
| 实验讲义 | `Source → Lesson/Evidence/Experiment` | 实验步骤与理论题分开；当前引擎缺实验结构 |

无法可靠映射的项目进入待确认清单，不使用空字符串或猜测补齐教师、年份、教材版次、答案或评分。

## Typed course engine 压力验证结果

现有引擎已经能表达课程、章节、知识点、证据、双视角关系、题干来源、答案权威/置信度、NUR/教师/出版答案评分和历史试卷题型；但真实材料证明以下结构仍不足：

| 已证明的缺口 | 真实材料证据 | 最小扩展方向 |
|---|---|---|
| 缺全局材料资产身份 | MAT-020/MAT-080 同哈希跨目录重复 | 增加按 SHA-256 唯一的 `MaterialAsset`，路径作为 aliases；课程 source 引用 asset id |
| 缺 source family / 派生关系 | 生理白皮 PDF/DOCX 同源；Codex 日稿派生于多份来源 | 增加 `familyId`、`derivedFromIds`、artifact version，不做 CMS |
| locator 过窄 | 当前 citation 只有单一 page/slide；真实资料需页、幻灯片、图片、表、题号和 OCR 区域 | 增加可重复的 typed locators，保留原页定位 |
| 缺转录/完整性/隐私状态 | 扫描 OCR、tracked changes、可见人物、文档元数据 | 增加 `transcriptionStatus`、`integrityStatus`、`privacyRisk`；禁止静态发布风险资产 |
| 单一答案不能表达冲突 | MAT-111/MAT-113 同题不同答案 | 答案增加 variants、conflict 状态和各自 sourceIds；未裁决时禁止 `verified` |
| 题目媒体结构不足 | 组胚识图 PDF/ZIP、显微图和标注需求 | Assessment 增加 media/regions/labels；不能把图片路径硬编码进 React |
| 题型虽然可用 `custom-*`，但缺结构化选项 | 不定项、多选、配伍、判断、识图均真实存在 | 小幅增加结构化 choices/matching groups，而非只存 prompt 字符串 |
| 固定四段 case 仅适合当前中诊训练 | 生理机制题、生化实验题、组胚识图不经过“证候/鉴别”四段 | 将 reasoning stages 变为课程配置；保留中诊默认四段模板 |
| Lesson 强制 transfer case | 术语、图像识别、实验步骤未必适合案例迁移 | 让 transfer/case 可选，但已完成中诊知识点保持原行为 |
| ExamBlueprint 当前必填且必须完整 | 生化/组胚只收到学生题型笔记，尚无当前 offering 正式方案 | 允许 `pending` blueprint，诚实显示待确认；不伪造 100 分结构 |
| SourceType 不足 | 实验讲义、答案键、批改样例、识图集、OCR 转录均不在枚举中 | 只增加被本批材料证明的少量类型 |

这些扩展应先落在内容/校验层；现有 React 页面不需要为任何单个文件硬编码。当前没有证据支持建设通用 CMS、导入后台、认证或服务端存储。

## 第二个真实知识点的证据排序

### 总体最充分：生理学「内环境与稳态」

它不是预设的“问寒热”，而是本批材料中跨权威层覆盖最完整的知识点：

- MAT-042 出版社《生理学》第4版目录明确将“内环境及其稳态”列为第一章第三节，教材印刷页 5–6。
- MAT-057/MAT-058 南京中医药大学生理学教研室白皮在第一章同时给出教学目标、题干、名词解释、简答题和参考答案；参考答案仍不等于当前教师采分点。
- MAT-070 课堂投影照片直接列出“体液、内环境（细胞外液）、相对稳定的稳态”。因包含人物，只能做本地来源定位，不能作为前端图片。
- MAT-043 把“什么是内环境的稳态？有何生理意义？”作为首个简答题并给出学生/汇编答案。
- MAT-054 的第3页把“稳态”列为名词解释；MAT-055 第3页出现“内环境的相对稳定状态称为____”填空题。

因此，从“真实材料压力验证引擎”的角度，第二条纵向闭环应优先考虑《生理学》`内环境与稳态`：它能验证 `western-primary`、教材/校教研室/历史试卷/学生答案分权、名词解释与简答共用知识点、题干与答案分源，以及无需强行构造中西医等同关系。

### 同一中诊试点内的备选：脾胃病辨证中的「脾气虚与脾阳虚鉴别」

如果下一步必须继续留在《中医诊断学》单课程，现有材料对脾胃病辨证的覆盖相对充分：MAT-004 有 17 页课件候选，另有复习汇编、导图、历史中诊试卷和既有项目中的官方教材来源。它仍缺当前教师身份、精确教材/题目 locator 和评分量表，因此只能作为备选，尚不足以直接写成 `verified` 训练闭环。
