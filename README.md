# Nur Landing

Interactive landing page for Nur, built with Next.js, React, TypeScript, and Tailwind CSS.

## Requirements

- Node.js 24+
- npm

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Checks

```bash
npm run lint
npm run typecheck
npm run build
npm run check
```

## Project Structure

```text
src/app/page.tsx      Main landing page
src/app/globals.css   Global styles and interaction design
src/app/layout.tsx    App shell and metadata
public/               Static assets
```

## Notes

The current homepage is an original monochrome interface inspired by layered AI product sites. It does not copy source logos, trademarks, or brand assets from reference websites.
